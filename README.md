# rag-empresas

Plataforma RAG multi-empresa: cada empresa se registra con su email, crea proyectos, sube documentos y los consulta por chat.

**Stack:** Next.js + NestJS en Vercel · Vercel Queues · Supabase (Auth, Postgres + pgvector, Storage) · Gemini · `multilingual-e5-small` (embeddings locales y gratuitos).

Flujo de ramas: ver [CONTRIBUTING.md](./CONTRIBUTING.md) (Gitflow).
